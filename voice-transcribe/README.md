# ボイスメモ文字起こし

iPhone のボイスメモを放り込むと、日本語のテキストが返ってくるツール。
PC のブラウザからも、同じ Wi-Fi にいる iPhone の Safari からも、同じ画面が使える。

要約はしない。文字起こしと校正だけ。

## 処理の流れ

```
音声ファイル (m4a など)
  ↓ ffmpeg  16kHz モノラルに正規化
  ↓ 10分ごとに分割（無音位置を探すので文の途中では切れない）
  ↓ Gemini API  各パートを文字起こし（前パートの末尾を文脈として渡す）
  ↓ Claude Code CLI  誤変換・句読点の校正（内容は変えない）
テキスト（画面表示 / コピー / .txt ダウンロード / output フォルダに保存）
```

## 初回セットアップ

### 1. API キーを取得する

<https://aistudio.google.com/apikey> にアクセスし、Google アカウントでログインして
「Create API key」でキーを発行する。無料枠があるので、まずは課金設定なしで試せる。

キーは `AQ.` で始まる文字列。ダイアログの「Copy key」ボタンでコピーする
（古い記事では `AIza` で始まると書かれていることがあるが、現在は形式が変わっている）。

### 2. .env を作る

`.env.example` を `.env` という名前でコピーし、`GEMINI_API_KEY=` の右側にキーを貼る。

```
GEMINI_API_KEY=AQ....ここにキー...
GEMINI_MODEL=gemini-3.6-flash
CHUNK_SEC=600
PORT=8000
```

### 3. 依存パッケージ（インストール済みなら不要）

```
python -m pip install -r requirements.txt
```

ffmpeg と claude コマンドは PATH に通っている必要がある。

## 使い方

`start.bat` をダブルクリックする。こう表示される。

```
  このPCから        : http://localhost:8000
  iPhone / 同じWi-Fi: http://192.168.x.x:8000
```

- **PC から**: `http://localhost:8000` を開いてファイルをドラッグ&ドロップ
- **iPhone から**: Safari で `http://192.168.x.x:8000` を開く
  → 「音声ファイルを選ぶ」をタップ → 「ファイルを選択」→「ファイル」アプリから m4a を選ぶ

IP アドレスは Wi-Fi をつなぎ直すと変わることがある。起動時の表示を毎回見ること。

初回起動時に Windows ファイアウォールの確認が出たら「プライベートネットワーク」を許可する。
許可しないと iPhone からアクセスできない。

終わるときは起動したウィンドウで `Ctrl + C`、またはウィンドウを閉じる。

### iPhone のボイスメモをファイルにする

ボイスメモアプリ → 録音を選ぶ → 共有ボタン → 「"ファイル"に保存」

## オプション

画面の「オプション」を開くと設定できる。設定はその端末に保存され、次回も引き継がれる。

| 項目 | 説明 |
|---|---|
| 用語集 | 人名・授業名・専門用語を1行ずつ書く。文字起こしと校正の両方に渡されるので、誤変換が大きく減る。**精度を上げたいならここが一番効く** |
| Claude で校正する | 同音異義語の誤変換と句読点を直す。オフにすると Gemini の生出力がそのまま出る |
| フィラーを除去する | 「えー」「あのー」を取り除く。オフなら話した通りに残す |

## 精度の実測

Windows の読み上げ音声で作った日本語の講義音声（30秒）で検証したところ、
`gemini-3.6-flash` の出力は**原稿と完全一致**した。同音異義語（化学結合／休講／連絡／教壇）も
すべて正しく、フィラーの「えー」も残った。所要 5.4 秒。

24分の音声では 3 パートに分割され、分割点は無音の中央に着地した（文の途中では切れない）。

## 設定を変えたいとき

`.env` を編集してサーバーを再起動する。

- `GEMINI_MODEL=gemini-3.5-flash` — 3.6 が不調なときの代替。精度は実測で同等だった
- `GEMINI_MODEL=gemini-3.1-pro-preview` — 課金を有効にしている場合のみ。無料枠だと 429 になる
- `CHUNK_SEC=300` — 分割を細かくする。1パートあたりが軽くなり、失敗時のやり直しも短い
- `PORT=8080` — 8000 番が他で使われている場合

## 保存場所

- 文字起こし結果: `output/` に `.txt` で残る
- アップロードした音声と作業用ファイルは、処理が終わると自動で消える

## 外出先からも使いたくなったら

Cloudflare Tunnel を足せば、PC が起動していれば外からも使える。
今の構成のまま後付けできる。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.py` | Web サーバー、ジョブ管理、起動時のIP表示 |
| `audio.py` | ffmpeg 呼び出し、無音検出、分割 |
| `transcribe.py` | Gemini 文字起こし、Claude 校正 |
| `config.py` | `.env` の読み込み |
| `static/index.html` | 画面（PC / iPhone 共用） |

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 画面上部に赤い警告が出る | `.env` の `GEMINI_API_KEY` が空。書いて再起動する |
| iPhone から開けない | 同じ Wi-Fi にいるか確認。ファイアウォールでプライベートネットワークを許可する。IP が変わっていないか起動時の表示を見る |
| 「校正はスキップされました」 | Gemini の文字起こし自体は成功している。生出力が表示されているのでそのまま使える |
| 429 エラーが出る | 無料枠のレート制限。少し待てば直る |
| 404「no longer available」が出る | モデルが提供終了になった。候補リストから自動で次のモデルに切り替わるので基本は放置でよい。ずっと出るなら `.env` の `GEMINI_MODEL` を書き換える |
| 固有名詞がずっと間違う | オプションの用語集にその単語を追加する |
