# AIで作った自分用ツール

UCLAの学生です。起業の検討と日々の勉強のために、Claude Code（AIのコーディングエージェント）と一緒に作った自分用のツールを2つ置いています。
コードはすべて Claude Code に指示して書かせ、動かして、直してもらいながら作りました。

| ツール | 一言で | デモ |
|---|---|---|
| [Startup Radar](startup-radar/) | 海外のスタートアップ情報を毎朝、日本語で「自分の事業との関連度」順に並べる | [デモを見る](https://sssfcb1109-dev.github.io/ai-tools-portfolio/) |
| [ボイスメモ文字起こし](voice-transcribe/) | iPhone の録音を放り込むと、校正済みの日本語テキストが返ってくる | 実行には API キーが必要なため、コードと説明のみ |

---

## 1. Startup Radar

**目的**：起業を検討中で、YC・a16z の動画や TechCrunch の記事を毎日追いたい。でも英語の記事と1時間の動画を全部読む時間はない。

**使ったツール**：Claude Code（開発と実行）、Claude Haiku / Sonnet（評価・要約・Web 検索による裏取り）、Python、RSS、YouTube の字幕

**取り組んだ内容**
- 毎日 3:00 に新着を集め、AI が日本語で要約し、事業関連度★1〜5とトレンド重要度🔥1〜3を付ける
- 安いモデル（Haiku）でふるい分け、★4以上だけを高性能モデル（Sonnet）が Web 検索で裏取りして深掘りする二段構え
- 動画は字幕から要約し、重要な場面にタイムスタンプを付けて、押すとその場面から再生できる
- 画面で★を直すと、その修正例が次回の指示文に入り、AIの採点が自分の感覚に寄っていく
- 自分の事業の「前提」を番号付きで AI に渡し、ニュースがどの前提を支持するか、覆すかをバッジで表示する

**結果**
- 1回の実行（約3.5分）で記事12本と動画1本を処理し、2本を深掘りした
- API で同じ処理をすると約 $0.44/回かかる。Claude Code のサブスクで動かしているので追加料金は 0 円
- 毎朝、関連度順に並んだ日本語の一覧ができている状態になった

## 2. ボイスメモ文字起こし

**目的**：授業や打ち合わせの録音（1時間超）を、読める日本語テキストにしたい。

**使ったツール**：Claude Code（開発）、Gemini API（文字起こし）、Claude（誤変換・句読点の校正）、FastAPI、ffmpeg

**取り組んだ内容**
- 長い音声を約10分ごとに分割する。無音の位置を探して切るので、文の途中では切れない
- 分割した各パートを Gemini で文字起こしする。前のパートの末尾を文脈として渡し、つなぎ目の精度を保つ
- Claude で同音異義語の誤変換と句読点だけを直す。内容は変えず、要約もしない
- 人名や専門用語の「用語集」を渡せるようにし、固有名詞の誤変換を減らした
- PC と、同じ Wi-Fi にいる iPhone の Safari の両方から使える

**結果**
- 30秒のテスト音声で、原稿と完全一致した（同音異義語もすべて正解、5.4秒）
- 24分の音声が3パートに分割され、分割点はすべて無音の中央に来た
- 実際に、1時間を超える録音の文字起こしに日常的に使っている
